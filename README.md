# Random Forest UNSW-NB15

## Deskripsi
Proyek ini merupakan aplikasi Machine Learning menggunakan algoritma Random Forest untuk melakukan klasifikasi berdasarkan dataset UNSW-NB15.

## Teknologi
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## Instalasi

Instal library yang dibutuhkan dengan perintah:

```bash
pip install -r requirements.txt
```

## Menjalankan Aplikasi

Jalankan aplikasi menggunakan perintah:

```bash
streamlit run app.py
```

## Struktur Proyek

- `app.py`: Program aplikasi.
- `requirements.txt`: Daftar library Python.
- `model/`: Tempat penyimpanan model Machine Learning.
- `data/`: Tempat penyimpanan dataset.

## Catatan
Pastikan file model yang dibutuhkan tersedia dan jalur file pada aplikasi sudah sesuai.
